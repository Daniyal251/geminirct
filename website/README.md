# RCT — Полная структура проекта

## 📁 Архитектура

```
geminirct/
│
├── website/              ← ГЛАВНЫЙ САЙТ + ВСЕ ПОРТАЛЫ
│   └── src/app/
│       ├── page.tsx                  # Главная визитка
│       ├── med/                      # Медоборудование
│       ├── sites/                    # Разработка сайтов
│       ├── content/                  # AI-контент
│       ├── ai/                       # ИИ-агенты
│       │
│       ├── client/                   ← КЛИЕНТСКИЙ ПОРТАЛ
│       │   ├── login/                # Вход для клиентов
│       │   └── dashboard/            # Личный кабинет
│       │
│       └── hub/                      ← АДМИНКА ДЛЯ СОТРУДНИКОВ
│           ├── login/                # Вход сотрудников
│           └── page.tsx              # Дашборд
│
├── hub-next/             ← ПОЛНОЦЕННАЯ АДМИНКА (Next.js + Supabase)
│   └── src/
│       ├── app/
│       │   ├── api/                  # API Routes
│       │   └── (dashboard)/          # Страницы управления
│       └── ...
│
└── client/               ← СТАРЫЙ клиентский портал (HTML)
    └── index.html        (можно удалить после переезда на website/)
```

---

## 🌐 Публичный сайт (визитка)

| Страница | URL | Описание |
|----------|-----|----------|
| Главная | http://localhost:3000 | 4 направления, статистика, CTA |
| Медоборудование | /med | КТ-сканеры, рентген, ПЭТ/КТ |
| Сайты | /sites | Разработка от 5 000₽ |
| AI-контент | /content | Видео, фото на нейросетях |
| ИИ-агенты | /ai | Telegram-боты, CRM, n8n |

---

## 👥 Клиентский портал

| Страница | URL | Описание |
|----------|-----|----------|
| Вход | http://localhost:3000/client/login | Регистрация / вход по телефону |
| Дашборд | /client/dashboard | Проекты, заявки, ИИ-помощник |

**Возможности:**
- 📊 Просмотр своих проектов
- 📋 Подача заявок на правки
- 💬 Чат с ИИ-помощником
- 🔔 Уведомления

## 🔐 Админка для сотрудников

| Страница | URL | Описание |
|----------|-----|----------|
| Вход | http://localhost:3000/hub/login | Вход для сотрудников |
| Дашборд | /hub | Управление проектами |

**Полная версия:** `hub-next/` (отдельный проект на Next.js)

---

## 🚀 Запуск

### Главный сайт (визитка + порталы)

```bash
cd website
npm install
npm run dev
```

Откроется **http://localhost:3000**

### Админка (полная версия)

```bash
cd hub-next
npm install
npm run dev
```

Откроется **http://localhost:3001** (нужно изменить порт)

## 🔐 Типы пользователей

| Тип | Вход | Возможности |
|-----|------|-------------|
| **Гость** | / | Просмотр визитки, заказ через форму |
| **Клиент** | /client/login | Проекты, заявки, ИИ-помощник |
| **Сотрудник** | /hub/login | Управление проектами, задачами |
| **Админ** | /hub/login | Полный доступ, настройки |

---

## 📊 Поток клиента

```
1. Гость заходит на главную
   ↓
2. Смотрит направления (/med, /sites, /content, /ai)
   ↓
3. Оставляет заявку (форма на /#contacts или /order)
   ↓
4. Регистрируется в клиентском портале (/client/login)
   ↓
5. Попадает в личный кабинет (/client/dashboard)
   ↓
6. Видит проекты, подаёт заявки на правки
   ↓
7. Общается с ИИ-помощником
```

- **Next.js 14** — React фреймворк

- **API Routes** — серверная логика
- **AI Cascade** — Groq → Gemini → Claude → DeepSeek

## 🔗 Навигация

### С главного сайта:
- **🏢** (иконка) → Клиентский портал
- **👤** (иконка) → Админка сотрудников
- **Заказать** → Форма связи

### Из клиентского портала:
- **Главная** → Дашборд с проектами
- **Проекты** → Список всех проектов
- **Заявки** → Подача заявок на правки
- **ИИ-помощник** → Чат с AI

### Из админки:
- **Проекты** → Управление проектами
- **Задачи** → Задачи сотрудников
- **Сотрудники** → Команда
- **Партнёры** → CRM
