# RKT HUB v14 — Модульная версия

Система управления проектами для RCT (Российские Компьютерные Технологии)

## 🚀 Быстрый старт

```bash
cd hub/src
npm install
npm run dev
```

Откроется http://localhost:3000

## 📁 Структура

```
src/
├── index.html          # Точка входа (~100 строк)
├── css/                # Стили (7 файлов)
│   ├── variables.css   # Темы, цвета, шрифты
│   ├── base.css        # Базовые стили
│   ├── components.css  # UI компоненты
│   ├── layout.css      # Layout
│   ├── pages.css       # Страницы
│   ├── modals.css      # Модальные окна
│   ├── ai-chat.css     # AI чат
│   └── mobile.css      # Адаптивность
└── js/
    ├── app.js          # Главное приложение
    └── modules/
        ├── config.js   # Конфигурация
        ├── auth.js     # Авторизация
        ├── data.js     # Данные (Supabase)
        ├── ui.js       # UI рендеринг
        ├── router.js   # Роутинг
        └── ai-chat.js  # AI-чат
```

## 📦 Зависимости

- **Vite** — сборщик
- **Supabase** — база данных
- **Groq/Gemini/Claude/DeepSeek** — AI модели

## 🔐 Вход

По умолчанию используется вход по телефону/паролю:
- Телефон: `+7 999 999 99 99`
- Пароль: (устанавливается в базе)

Или через Telegram WebApp в боте @AIhroject_bot

## 🤖 AI-чат

Встроенный AI-ассистент с каскадом моделей:
1. **Groq** (бесплатно, 1000 запросов/день)
2. **Gemini** (бесплатно, 1500 запросов/день)
3. **Claude** (платно, лучшее качество)
4. **DeepSeek** (дёшево, хорошо на русском)

Настройка в админ-панели → Ключи API
